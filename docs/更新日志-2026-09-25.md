## 二、跨页保留选择落地 · 规范 5.4 闭环（3d0e4bb）

- 勾选状态按页面路径存 sessionStorage（`nv-bulk:<path>`）：翻页 / 改页大小 / 筛选后自动回填
- 批量操作条计数 = 记忆集合总数（含其它页已勾选行），按钮启停同步按总数判定
- 批量提交时记忆集合并入 `keys` 参数；操作成功后自动清空记忆，「取消选择」一键清空
- sessionStorage 不可用（隐私模式等）时静默降级为页内选择

### 连带修复：原生补齐 data-action 契约

- Nova 布局不加载 Cube 核心的 jQuery `Cube.js`，批量操作条、行内删除/恢复、高级菜单（删除选中/同步/备份/清空）、文件导入此前**全部无响应**
- `nova-ui.js` 新增 `initBulkAction`：原生 fetch 实现同一契约（`data-action="action"|"upload"`、`data-confirm`、`data-method`、`data-fields`；响应 `{message|data, url, time}` → toast + `[refresh]` 刷新/跳转）
- **修复工具栏脚本解析期绑定缺陷**：_List_Toolbar / _List_BulkBar 内联脚本在表格解析完成前执行，`querySelector('.nv-table')` 返回 null 导致整体早退——全选/按钮启停/取消选择自 Nova 皮肤上线以来即失效；现改 DOMContentLoaded 绑定
